# Standalone Expressive import/export transfer flow

Task 12 adds typed Import/Export routes, Activity-owned document/page launchers, backend-owned APKG/CSV pages, native COLPKG replacement, scoped exports, Create Document saving, and canonical FileProvider sharing without entering the Classic shell. Collection scope, lifecycle ownership, saved-state hygiene, and destructive collection boundaries still have shipping blockers. Watch for: **confirmed P1** deck COLPKG exports disclose the whole collection; **confirmed P1** picker/save follow-up work can lose terminal results on recreation; **confirmed P1** raw paths and provider-derived names enter saved state; **confirmed P1** COLPKG replacement can proceed after a swallowed close failure; **likely P1** committed COLPKG replacement can miss global invalidation; **confirmed P1** external imports are re-consumed after process death; **confirmed P1** failed staging leaks up to 4 GiB per attempt; **confirmed P2** wrong canonical export defaults; **confirmed P2** no core transfer contract coverage.

**Verdict**: NEEDS_CHANGES

## High-level view

The coordinator converts restored running operations to Interrupted, but provider copies remain owned by `ExpressiveHomeActivity.lifecycleScope`. Activity Result delivery can therefore be consumed before durable state advances, stranding an import or deleting an export before success is recorded (**confirmed P1**).

APKG/text scopes become exact `ExportLimit` values, while COLPKG bypasses the limit. Deck export still offers COLPKG under a deck label, so it exports every deck (**confirmed P1**); whole and selection defaults also diverge from Classic (**confirmed P2**).

COLPKG work holds the serialized collection queue, but replacement uses a close helper that swallows failures and export closes before its reopen `try/finally` (**confirmed P1**). Replacement invalidation is a later cancellable Main-context step, leaving a commit-without-invalidation window (**likely P1**).

Failed input copies are not removed and import/selection caches have no stale cleanup (**confirmed P1**). The persisted state also contains absolute cache/token paths and provider-derived display names (**confirmed P1**).

External VIEW/SEND bootstraps Expressive while explicit Classic routing remains intact. Consumption is recorded only by mutating the in-memory Intent, so process recreation can overwrite an interrupted import and discard a late result (**confirmed P1**).

## Deck-labelled COLPKG bypasses the deck limit

**Confirmed P1.** `TransferScreen.kt:177-186` restricts only selection scopes and gives deck scopes every format, including COLPKG. `ExpressiveTransferCoordinator.kt:539-541` computes a deck `ExportLimit` but dispatches COLPKG to `exportCollectionPackageGuaranteed()` without it. A deck-labelled export can therefore contain all decks, notes, scheduling, and media.

`ExpressiveTransferCoordinator.kt:746-749` accepts any `ExpressiveExportOptions`, so UI filtering alone is insufficient. Define valid format/scope pairs centrally and reject them when updating and confirming options; either disallow COLPKG outside `WholeCollection` or require an explicit switch to whole-collection scope.

## Picker and Create Document results outlive copy jobs

**Confirmed P1.** The picker consumes its result at `ExpressiveHomeActivity.kt:126-133`, then `stageImportIntent()` starts the potentially 4 GiB copy in `lifecycleScope` at lines 441-454. Recreation after delivery cancels the old scope while the retained coordinator remains `PickingImport(launchDispatched=true)`; the new Activity has neither a result nor a launch effect to resume.

The save callback repeats this gap at `ExpressiveHomeActivity.kt:144-158`. `copyReadyToProvider()` deletes the source before returning at `ExpressiveTransferCoordinator.kt:373-385`; cancellation or death before `saveFinished()` restores Ready with a missing artifact and loses the terminal result.

Move post-result I/O to retained ownership and enter an explicit non-replayable copying state first. Commit save success before deleting the source; process death should retain the source and expose Interrupted/retry without persisting the destination URI.

## Saved snapshots expose paths and authorize cleanup

**Confirmed P1.** `ExpressiveTransferCoordinator.kt:57-82` serializes selection token paths. Its states serialize provider-derived `displayName` and absolute `cachePath`, `ownedPath`, `artifactPath`, and `retainedArtifactPath` at lines 133-169, then write the complete JSON to `SavedStateHandle` at lines 862-863. `completeBackendImport()` and launch failure subsequently call `File(path).delete()` at lines 706 and 721 instead of resolving an owned canonical child.

Persist only a versioned request ID, typed format/scope metadata, counts, and opaque basenames. Keep provider names memory-only or use generic restored labels, and route all reads/deletes through canonical import/export/selection resolvers.

## COLPKG can mutate after close failure

**Confirmed P1.** `CollectionManager.importColpkg()` invokes `ensureClosedInner()` at `CollectionManager.kt:506-511`; that helper catches `collection.close()` failures and still nulls the wrapper at lines 307-317. Replacement can therefore mutate `collection.anki2` while the previous connection remains open, despite `ensureClosedStrictInner()` already existing at lines 298-305.

`exportCollectionPackageGuaranteed()` calls `close()` before entering its `try/finally` at `CollectionManager.kt:526-535`, so a partial close failure never reaches `reopen()`. Use strict replacement close and include the whole export close/backend/reopen protocol in recovery that restores a usable wrapper or exposes an explicit recovery failure.

## Replacement notification sits outside commit

**Likely P1.** `DefaultExpressiveTransferGateway.replaceCollection()` returns from `importColpkg()` before entering cancellable `withContext(Dispatchers.Main)` for notification at `ExpressiveTransferCoordinator.kt:513-529`. `cancel()` also aborts the backend and cancels the job. If replacement completes despite abort, cancellation can prevent the Main hop, report cancellation, and leave Home/Browse/Study/Stats uninformed about the new collection.

Publish the single global invalidation non-cancellably as part of successful replacement. Cancellation before commit may fail; cancellation after commit must still invalidate and report committed success.

## External import is consumed only in memory

**Confirmed P1.** `consumeExternalImportIntent()` removes URI fields only from the local Intent at `ExpressiveHomeActivity.kt:457-470`. After process death, the original external Intent can return while restored Running has become Terminal Interrupted; `startExternalImport()` accepts Terminal at `ExpressiveTransferCoordinator.kt:618-622`, replaces it with Picking, and stages again. A backend-page result delivered afterward no longer matches Running and is ignored.

Persist consumption/request identity before staging and gate consumption on a fresh coordinator with no restored request. Preserve Interrupted until acknowledgement; retry must be an explicit new action with a new request ID.

## Import and selection caches lack failure cleanup

**Confirmed P1.** `stageImport()` creates output at `ExpressiveTransferCoordinator.kt:280-301`, but its `runCatching` has no failure cleanup. A provider with unknown size can stream until the 4 GiB check throws and leave the whole partial file; repeated attempts can exhaust storage. `cleanupStale()` runs only for exports, while selection tokens also survive option cancellation and interrupted export.

Delete output on every unsuccessful stage, sweep only canonical regular files under bounded import/selection roots, and delete selection tokens when options are cancelled or an operation restores as Interrupted.

## Scope defaults diverge from Classic

**Confirmed P2.** `ExpressiveTransferCoordinator.kt:725-744` defaults note/card selections to text and every other scope to APKG. `ExportDialogFragment.kt:76-87` defaults whole collection to COLPKG and deck/selection to APKG. Set `WholeCollection -> COLPKG` and `Deck/Selection -> APKG`.

## Routing tests do not exercise transfer behavior

**Confirmed P2.** `IntentHandlerTest.kt:164-198` verifies bootstrap destinations and explicit Classic selection, but no test references `ExpressiveTransferCoordinatorViewModel`, `ExpressiveTransferFiles`, `ExpressiveImportPageActivity`, exact `ExportLimit`, or COLPKG close/reopen/invalidation. The parity contract also has no Task 12 row.

Add coverage to existing permitted test files. Compilation and `IntentHandlerTest` pass. A combined `DeckPickerTest` run completed 115 tests with three failures in the pre-existing dirty startup/test harness, including `deckPickerOpensWithHelpMakeAnkiDroidBetterDialog` failing during recreation on uninitialized `floatingActionMenu`; this is a validation limitation, not attributed to Task 12.
